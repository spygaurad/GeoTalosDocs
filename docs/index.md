# GeoTALOS documentation

GeoTALOS is a geoscience platform for automated landscape observation and spatial analysis. You bring your own imagery and models, and GeoTALOS connects them to areas of interest, expert review, map layers, reports and provenance in one place.

## Where to start

- **Ecologists and field teams:** start with [Key Concepts](concepts/index.md), then the [User Guide](user-guide/index.md) and the step by step [Tutorials](tutorials/index.md).
- **Developers:** see the [Developer Guide](developer/index.md) for architecture, setup, the API and extending the platform.
